# Zapdude 1.4.4

Release date: 2026-11-03.

Built with AI assistance (OpenCode + the GLM-5.3 Flash model by Z.ai),
everything verified on real hardware before shipping. Update from 1.4.3
keeps every account and session intact (the data folder is never touched
by the installer).

## The permission shield

- Zapdude is now the gatekeeper of your devices: when a chat page asks
  for the microphone, camera, screen or clipboard, the answer comes from
  YOUR switches in the Security section. OFF means the app inside gets
  refused (the "sites are listening" question dies at the door); ON
  keeps the video call flows alive. States persist between runs.
- Twitch joins the embedded surfaces (six services): the whisper trails
  read with the same adaptive bridging as the rest, marked
  read-only-first like every new surface until proven live.

## The polish round

- The "+" strip returns to the proven recreate-per-open choreography
  (the cached warm variant was found unreliable under rapid clicking;
  reliability first), the options drawer confirms installs inside the
  app (the raw browser dialog is gone forever), the boot curtain shows
  the brand of the service being opened (WhatsApp green, twitch purple,
  X dark, instagram gradient, tiktok red/black), and the network lens
  reports account names without the duplicated prefix.

## Updating

- Both the 1.4.2 and the 1.4.3 installed bases see this release through
  the built-in updater; from 1.4.3 the flow shows the centered
  "New version is ready" card with the don't-show-again checkbox.
- Windows setup: Zapdude_1.4.4_x64-setup.exe (per-user, silent update
  path included).
