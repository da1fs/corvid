Security

What is already running for every account: the embedded pages can only navigate their own site (browser-level guard: other links and file pages are refused), chat links open in your own browser, the shell accepts only its own pages (remote sites are refused), known third-party trackers are blocked before they leave the machine, and every host the chats touch is recorded below. The blocked list is curated and static, and the chat services still see what their own pages do; the lens is here so that stays observable.

Live per-account hosts the chat pages contacted; blocked rows never left your machine

The permission shield. When a chat page asks for a device (microphone, camera, screen, clipboard), Corvid is the gatekeeper that answers: ON passes to the device, OFF is refused inside the app. Turn anything off and the page simply gets "no" (your calls keep working on whatever you leave ON).

About

Corvid

Multi-service desktop chat hub (WhatsApp, Messenger, Instagram, X, TikTok, Twitch) written in Rust with Tauri 2 and the system webviews. No automation surface: the app is a well-set browser, not a bot.

License AGPL-3.0. An original project by da1fs (github.com/da1fs).

The starting point was ZapZap by Rafael Tosta: his design and behavior were the reference for the first releases, and the implementation then grew into something substantially different on its own stack. ZapZap's code does not ship here. Credit where credit is due.

Built with AI assistance: OpenCode + the GLM-5.3 Flash model (by Z.ai). The author reviews, tests and ships every change on real hardware.

Not an official WhatsApp product; not affiliated with WhatsApp or Meta.
